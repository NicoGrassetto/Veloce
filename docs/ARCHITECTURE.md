# Architecture

## Technology stack

Veloce is a documentation-based, tool- and model-agnostic software engineering
harness, not a prescribed application stack. See the [project overview](../README.md#overview).

| Area | Technology | Role |
|---|---|---|
| Documents and instructions | Markdown | Project documentation and agent workflows. |
| Skill metadata | YAML frontmatter | Skill names and discovery descriptions. |
| Version control and hosting | Git and GitHub | Versioned source, documentation, and repository skills. |

No application language, runtime, framework, database, or deployment platform is
currently selected. Those technologies are chosen for each adopting project
from its requirements and constraints; Veloce does not mandate them.
