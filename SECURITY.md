# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public issues, discussions, or pull requests.

Use [GitHub's private vulnerability reporting](https://github.com/NicoGrassetto/Veloce/security/advisories/new) to share:

- A description of the vulnerability and its potential impact.
- The affected component or files.
- Reproduction steps or a proof of concept.
- Any suggested remediation, if available.

Reports will be reviewed as soon as possible. Please allow time for a fix to be prepared before publicly disclosing the vulnerability.
