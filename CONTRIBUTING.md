# Contributing to Veloce

Thank you for helping improve Veloce.

## Before you start

- Check existing issues and pull requests to avoid duplicating work.
- Open an issue before making a substantial change so the approach can be discussed.
- Keep each contribution focused on one problem or improvement.

## Making a contribution

1. Fork the repository and create a branch from `main`.
2. Make your changes using the existing style and structure.
3. Update relevant documentation.
4. Verify the behavior affected by your change.
5. Open a pull request that explains the problem, the solution, and how it was verified.

By contributing, you agree that your contribution will be licensed under the [MIT License](LICENSE).
